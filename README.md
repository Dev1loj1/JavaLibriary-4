# Лабораторная работа 4 — коллекции

Вариант 1: учёт книг читального зала. Программа загружает журнал из 10 записей, удаляет повторные книги, группирует их по жанрам, сортирует по году, автору и названию, находит крайние годы издания и подсчитывает книги авторов после списания изданий до 1950 года.

Запуск: класс `Main`. Тесты JUnit 5 находятся в `test/MainTest.java`; при наличии Maven запускаются командой `mvn test`.

Для журнала используется `ArrayList`: он сохраняет порядок записей и позволяет последовательно их обходить. `LinkedHashSet` удаляет повторы и сохраняет порядок первого появления книги. `TreeMap` упорядочивает названия жанров и имена авторов по алфавиту.
